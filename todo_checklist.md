## 🔌 Блок 2: Разработка REST API (Префикс `/api/v1`)

### 2.1. Модуль Аналитики (`/analytics`)
- [ ] **Реализовать эндпоинт `GET /analytics/summary`:**
  - [ ] **Собрать объект `financials`:** рассчитать общую сумму выигранных сделок (`totalVolume`), средний чек (`averageBudget`) и количество сделок без запланированных/незакрытых задач (`forgottenDealsCount`).
  - [ ] **Собрать объект `funnel`:** рассчитать конверсию переходов в финальную стадию (`conversionRate`), выявить стадию с наибольшим оттоком лидов (`weakestStage`) и посчитать среднее время нахождения карточек на каждой стадии (`averageStageDurations`).
  - [ ] **Собрать геймификацию `gamification`:**
    - [ ] Сформировать массив `boardOfHonor`: топ менеджеров, отсортированных по убыванию суммы закрытых сделок (`wonBudget`).
    - [ ] Сформировать массив `dangerZone` (Зона риска): список менеджеров, у которых есть нарушения SLA, с расчетом процента нарушений от их общего числа сделок, общего количества нарушений и среднего времени опоздания в минутах.

### ⚙️ Блок 4: Фоновый контроль SLA (Cron-процесс)

- [ ] **Инициализировать планировщик задач:**
  - [ ] Настроить Cron-задачу на выполнение с интервалом ровно в 1 минуту (`*/1 * * * *`).
- [ ] **Реализовать логику сканирования БД:**
  - [ ] Написать TypeORM-запрос для поиска всех сделок, соответствующих трем жестким условиям одновременно:
    1. Статус сделки равен `'NEW'`.
    2. Флаг нарушения `isSlaViolated` равен `false`.
    3. Время дедлайна `slaDeadline` меньше текущего системного времени бэкенда (`LessThan(new Date())`).
  - [ ] Подгрузить связь (`relation`) ответственного менеджера `user`.
- [ ] **Реализовать цикл обработки просроченных сделок:**
  - [ ] Для каждой найденной сделки в транзакции обновить флаг `isSlaViolated = true`.
  - [ ] Рассчитать количество минут просрочки (`Текущее_время - slaDeadline`).
  - [ ] Сделать запись в таблицу `SlaLog`, привязав ID сделки и ID менеджера (если он был назначен).
  - [ ] Вызвать сокет-метод `NotificationGateway.sendSlaViolated` для отправки мгновенного алерта на фронтенд всей команде.
